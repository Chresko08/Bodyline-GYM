# Bodyline Gym

Welcome to the Bodyline Gym website repository! This is a static, responsive single-page website for Bodyline Gym located in Prayagraj.

## Features

- **Responsive Design**: Looks great on both desktop and mobile devices.
- **Modern UI**: Clean and energetic layout with a dark theme and red accents.
- **Smooth Animations**: Intersection Observer used for subtle fade-in and slide-up animations.
- **Navigation**: Mobile-friendly toggle menu and smooth scrolling to sections.

## Technologies Used

- HTML5
- CSS3 (Variables, Flexbox, CSS Grid)
- Vanilla JavaScript
- Google Fonts (Inter, Oswald)
- Font Awesome Icons

## Sections

1. **Hero**: Main banner with a call to action.
2. **Quick Info**: Timing and location details.
3. **Amenities**: Highlights of what the gym offers.
4. **Schedules**: Various workout splits for members.
5. **Trainer**: Profile of the head trainer.
6. **Contact**: Address, phone, and embedded Google Maps for directions.

## Setup Instructions

Simply clone the repository and open `index.html` in your web browser. No build steps or local server required!

```bash
git clone <repository-url>
```
